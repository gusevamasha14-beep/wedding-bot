# 🎁 Телеграм-бот "Подарочный сертификат"

Простой бот для вручения сертификата на фотосессию молодожёнам Александру и Александре от Миланы.

## 🚀 Быстрый запуск на Railway.app (бесплатно)

### Шаг 1: Создайте бота в Telegram

1. Откройте [@BotFather](https://t.me/BotFather) в Telegram
2. Отправьте команду `/newbot`
3. Придумайте имя для бота (например: "Подарочный сертификат")
4. Придумайте username (например: "wedding_gift_bot")
5. **Сохраните токен** (длинная строка вида: `1234567890:ABCdefGHIjklMNOpqrsTUVwxyz`)

### Шаг 2: Загрузите файлы в GitHub

1. Создайте новый репозиторий на [GitHub](https://github.com/new)
2. Сделайте его публичным (Public)
3. Загрузите в репозиторий все файлы:
   - `bot.py` — код бота
   - `config.json` — тексты сообщений
   - `certificate.jpg` — изображение сертификата (**важно!**)
   - `requirements.txt` — зависимости (пустой файл)
   - `Procfile` — команда запуска для Railway
   - `.env.example` — пример переменных окружения
   - `README.md` — эта инструкция

### Шаг 3: Деплой на Railway

1. Зайдите на [railway.app](https://railway.app)
2. Войдите через GitHub
3. Нажмите **"New Project"**
4. Выберите **"Deploy from GitHub repo"**
5. Выберите созданный репозиторий
6. Railway автоматически обнаружит `Procfile` и начнёт деплой

### Шаг 4: Добавьте токен бота

1. В Railway откройте ваш проект
2. Перейдите на вкладку **"Variables"**
3. Нажмите **"New Variable"**
4. Заполните:
   - **Variable name**: `BOT_TOKEN`
   - **Value**: ваш токен от @BotFather
5. Нажмите **"Add"**

Railway автоматически перезапустит бота с новым токеном.

### Шаг 5: Проверьте работу

1. Откройте вашего бота в Telegram по ссылке `https://t.me/ваш_бот_username`
2. Нажмите **Start** или отправьте `/start`
3. Бот должен прислать приветствие с кнопкой "ОТКРЫТЬ ПОДАРОК"
4. После нажатия на кнопку появится сертификат с кнопкой "ИСПОЛЬЗОВАТЬ СЕРТИФИКАТ"
5. Кнопка должна вести на профиль @callipigiam

## 🎯 Как работает бот

1. Пользователь запускает бота командой `/start`
2. Бот присылает приветственное сообщение от Миланы
3. Пользователь нажимает кнопку "ОТКРЫТЬ ПОДАРОК"
4. Бот отправляет изображение сертификата
5. Кнопка "ИСПОЛЬЗОВАТЬ СЕРТИФИКАТ" ведёт в Telegram на @callipigiam

## 📝 Редактирование текстов

Все тексты находятся в файле `config.json`:

- `start_text` — приветственное сообщение
- `certificate_caption` — текст под сертификатом
- `photographer_username` — ваш Telegram username (уже настроено: @callipigiam)
- `certificate_file` — имя файла сертификата (должно быть `certificate.jpg`)

После изменения файла:
1. Сохраните изменения в GitHub
2. Railway автоматически перезапустит бота с новыми текстами

## ⚠️ Важно!

1. **Имя файла сертификата** должно быть точно `certificate.jpg` (или измените `certificate_file` в config.json)
2. **Токен бота** храните в секрете, никому не показывайте
3. **Бесплатный лимит Railway** — $5 кредитов в месяц (хватает для работы простого бота 24/7)

## 🐛 Решение проблем

**Бот не отвечает:**
- Проверьте логи в Railway (вкладка "Deployments")
- Убедитесь, что токен правильный
- Проверьте, что файл `certificate.jpg` загружен

**Сертификат не отправляется:**
- Убедитесь, что файл называется точно `certificate.jpg`
- Проверьте размер файла (не больше 10 МБ)

**Бот "crashed":**
- Откройте вкладку "Deployments" в Railway
- Кликните на последний деплой
- Прочитайте логи — там будет точная причина ошибки
