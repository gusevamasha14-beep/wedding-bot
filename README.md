# 🎁 Телеграм-бот "Подарочный сертификат"

Интерактивный бот для вручения сертификата на фотосессию молодожёнам.

## 🚀 Быстрый запуск на Railway.app (бесплатно)

### Шаг 1: Создайте бота в Telegram

1. Откройте [@BotFather](https://t.me/BotFather) в Telegram
2. Отправьте команду `/newbot`
3. Придумайте имя и username для бота
4. Скопируйте полученный токен (выглядит так: `1234567890:ABCdefGHIjklMNOpqrsTUVwxyz`)

### Шаг 2: Подготовьте файлы

1. Переименуйте файл бота в `bot.py`
2. Убедитесь, что файл `certificate.jpg` находится в той же папке
3. Файл `config.json` уже настроен с текстами

### Шаг 3: Загрузите на Railway

1. Зайдите на [railway.app](https://railway.app) и войдите через GitHub
2. Нажмите **"New Project"** → **"Deploy from GitHub repo"**
3. Если у вас ещё нет репозитория:
   - Создайте новый репозиторий на GitHub
   - Загрузите туда файлы: `bot.py`, `config.json`, `certificate.jpg`, `Procfile`, `requirements.txt`
4. Выберите ваш репозиторий в Railway
5. Railway автоматически определит настройки из `Procfile`

### Шаг 4: Добавьте токен бота

В Railway:
1. Откройте ваш проект
2. Перейдите в **Variables** (вкладка сверху)
3. Нажмите **"New Variable"**
4. Добавьте:
   - **Key**: `BOT_TOKEN`
   - **Value**: ваш токен от BotFather
5. Нажмите **"Add"**

### Шаг 5: Деплой

Railway автоматически задеплоит бота после добавления токена. Бот начнёт работать в течение 1-2 минут.

## 📝 Как редактировать тексты

Все тексты бота находятся в файле `config.json`:
- `start_text` - приветственное сообщение
- `steps` - вопросы и варианты ответов
- `certificate_caption` - текст при вручении сертификата
- `photographer_username` - ваш Telegram username (уже установлен: @callipigiam)

После изменения `config.json`:
1. Закоммитьте изменения в GitHub
2. Railway автоматически перезапустит бота с новыми текстами

## 🆘 Проблемы?

**Бот не отвечает:**
1. Проверьте логи в Railway (вкладка "Deployments")
2. Убедитесь, что токен правильный
3. Проверьте, что файл называется `bot.py`, а не с длинным именем

**Сертификат не отправляется:**
- Проверьте, что `certificate.jpg` загружен в репозиторий
- Имя файла должно быть точно `certificate.jpg`
